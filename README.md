# quja’ for AnySoftKeyboard

A Latin-script Klingon keyboard layout add-on for AnySoftKeyboard. This repository contains the project website and privacy policy.

## GitHub Pages

In the repository settings, open **Pages**. Under **Build and deployment**, choose **Deploy from a branch**, then select branch **main** and folder **/(root)**. The site will be published at:

https://cyberman-tm.github.io/quja_keyboard/

Privacy policy: https://cyberman-tm.github.io/quja_keyboard/privacy.html

The Android add-on source is included in this repository under [`android/`](android/).
The Klingon language-pack project is located at
[`android/addons/languages/tlhingan/`](android/addons/languages/tlhingan/).
