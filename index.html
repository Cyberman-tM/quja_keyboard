01

What it is

quja’ is a community keyboard layout add-on. It provides a four-row Latin-script layout for use in the AnySoftKeyboard app.

02

Current status

The project is in development. pIqaD support and dictionary suggestions are not included in the current package.

03

Privacy

The quja’ add-on does not collect or transmit what you type. Read the full privacy policy for details about the add-on and this website.
