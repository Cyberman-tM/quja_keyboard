Four rows.
One compact pattern.

Writing tlhIngan Hol on a standard QWERTY keyboard means reaching for Shift and pressing multiple keys for a single Klingon letter. On a phone, every key takes up precious space. That's why I made quja'.

Each Klingon letter has its own key, including ch, gh, ng and tlh. The new layout produces ordinary Latin text, regardless of how the keys are displayed.

So why not keep the keys as close to QWERTY as possible?
Fair question. Counter-question: where would be the fun in that? jIqIDneH…
More seriously, QWERTY was designed for English and a mechanical device. I wanted a layout designed for Klingon on a handheld device.

I started by counting letter frequencies in a word list from Klingonska Akademien and the restored Klingon translation of Hamlet. The results served as a rough guide, but structure and symmetry were just as important.

Although tlh is actually one of the least frequent letters, it deserves a prominent place — after all, tlhIngan begins with it (not to mention the equally important word tlhutlh). t sits nearby, ch, gh and ng provide symmetry, and q and Q stay close together.

I also wanted the top line to read quja'. It may be a nonsense word, but it runs off the tongue as if it could be real.

What it does

It makes typing Klingon easier. Capital letters and multi-letter sounds have dedicated keys, and the usual keyboard is still close by when you need it.

What it doesn't

quja' does not translate text. The output will be the keys you press: Latin letters in the Latin layout, or the Unicode encoding for pIqaD in the Unicode layout.

How to type

That's up to you. I found it comfortable to type one-handed: the keys form a pattern of three columns, one column, then three columns. Keeping your hand near the top row makes the keys easy to reach.

Install
quja'.

AnySoftKeyboard first

quja' is an add-on for AnySoftKeyboard (ASK), not a standalone keyboard. Install ASK first, then install the quja' add-on as well.

  1. Install and enable AnySoftKeyboard.
  2. Install quja'.
  3. In ASK's settings, open the language or keyboard-layout section, enable the Klingon quja' layout, and select it when typing.

Unicode pIqaD

The Unicode layout uses the established CSUR mapping for Klingon pIqaD. To see the glyphs, your device or app needs a compatible font.

For an overview of available fonts and platform-specific advice, see the Klingon Wiki font guide. Font sources include pIqaD qolqoS, the Evertype Klingon pIqaD fonts, and the Klingon fonts collection.

  1. Download a font that supports the CSUR pIqaD range.
  2. Install it using your device's font manager or the method recommended for your platform. On a computer, opening a TTF or OTF file usually offers an install option.
  3. Select the Unicode pIqaD layout in ASK and test it in an app that can use the installed font.
