Privacy policy

Effective date: 16 November 2026

This policy applies to the quja' keyboard layout add-on ("quja'") and this project website. The add-on is an optional layout for the separate AnySoftKeyboard application.

Information handled by quja'

The quja' add-on does not collect, store, or transmit personal information or the text you type. It contains no analytics and makes no network connections. It does not require an account. The add-on provides keyboard layout resources to AnySoftKeyboard; it is not itself the keyboard service that receives your keystrokes.

AnySoftKeyboard

When you type, the AnySoftKeyboard app handles keyboard input. Its own data practices are described in the AnySoftKeyboard privacy policy. Installing the quja' layout does not change that app's privacy practices.

This website

This website does not use analytics, advertising, cookies, or third-party tracking scripts. It is hosted by GitHub Pages. GitHub may process technical request data to provide and secure its hosting service under the GitHub Privacy Statement.

Sharing, retention, and deletion

The quja' add-on does not collect personal information, so it has no personal information to share, retain, or delete. The project maintainer does not receive the text you type through this add-on.

Children

quja' does not knowingly collect personal information from anyone, including children.

Changes and contact

If this policy changes, the updated version and effective date will be published here. For privacy questions, contact the project maintainer through GitHub Issues.

Datenschutzerklärung (Deutsch)

Diese Erklärung gilt für das quja'-Tastaturlayout für AnySoftKeyboard und diese Projektwebsite. Das Add-on sammelt, speichert und überträgt keine personenbezogenen Daten und keinen eingegebenen Text. Es enthält keine Analysefunktionen und stellt keine Netzwerkverbindungen her. AnySoftKeyboard verarbeitet die Tastatureingaben; dazu gelten die Datenschutzbestimmungen von AnySoftKeyboard.

Diese Website verwendet keine Analyse-, Werbe- oder Tracking-Cookies und keine Tracking-Skripte. Sie wird über GitHub Pages bereitgestellt; technische Zugriffsdaten können gemäß der GitHub-Datenschutzerklärung verarbeitet werden.

Da das quja'-Add-on keine personenbezogenen Daten erhebt, gibt es über das Add-on keine personenbezogenen Daten weiter und speichert oder löscht solche Daten auch nicht. Fragen zum Datenschutz: GitHub Issues.
