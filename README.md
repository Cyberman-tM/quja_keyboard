# quja’ for AnySoftKeyboard

A Klingon keyboard layout add-on for AnySoftKeyboard. This repository contains the Android source, language-pack resources, website, and privacy policies.

## Repository layout

- `android/` — Android source and AnySoftKeyboard language-pack project
- `docs/index.html` and `docs/style.css` — website source
- `privacy.html` and `privacy-scrabble.html` — privacy policies kept at the repository root

## GitHub Pages

Pages continues to publish from branch `main` and the repository root. The website source lives in `docs/`; Jekyll publishes `docs/index.html` at the site root using its `permalink: /` front matter. The privacy pages stay in the repository root and remain available at:

- https://cyberman-tm.github.io/quja_keyboard/privacy.html
- https://cyberman-tm.github.io/quja_keyboard/privacy-scrabble.html

The public site is also used by https://quja.tlhingan.at/.

The Klingon language-pack project is located at
[`android/addons/languages/tlhingan/`](android/addons/languages/tlhingan/).
